# Publish Financial Twin

Put the app online at a public link you can send to judges.

## What happens

1. Security check — already run, nothing flagged.
2. Publish the current version of the app. No code, numbers, or wording change.
3. You get a public `.lovable.app` link that works without a Lovable login.

## Notes

- Deployment usually takes about a minute after the request goes out.
- The link can be renamed later, and a custom domain can be connected from Project settings > Domains.
- Future changes go live only when you publish again.
